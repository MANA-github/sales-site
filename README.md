# Sales Site

This project is the completed version of the prototype cafeteria ordering system. It has evolved from an experimental concept to a fully operational web application.

## Development Objective

This system was designed to eliminate long queues at the university cafeteria's ticket vending machines and improve the overall student dining experience.

By allowing direct ordering from seats, unnecessary waiting times are eliminated, enabling more effective use of time between classes.

Implementing such a system requires cooperation and consultation between the university and the cafeteria operators. Therefore, this project should be viewed not merely as a tool to enhance individual convenience, but as a proposal for overall organizational improvement.

## Features

* Order meals from your smartphone or PC
* Reduce waiting times at ticket vending machines
* Improve cafeteria workflow efficiency
* Responsive Web Interface
